Privacy Policy for InkPad

InkPad is a personal, single-user desktop application and is not distributed to the public.

What data InkPad accesses

When connected to Google Drive, InkPad only accesses the specific files and folder that the user explicitly creates or opens with InkPad, using Google's restricted "drive.file" permission. InkPad cannot see or access any other files in the user's Google Drive account.

How data is used

Documents and annotation data are stored in the user's own Google Drive account solely so the user can access their own documents. Data is downloaded to the user's own computer only temporarily, while a document is open, and is never shared with any third party.

Data sharing

InkPad does not sell, share, or transmit user data to any third party or external service. No analytics or tracking is performed.
